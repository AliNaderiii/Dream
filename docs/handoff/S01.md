## What changed, and why

### 1. `Ledger.consume` is atomic — and durable

`_save` already used a temp file; it now also `flush()`es and `fsync()`s
before `os.replace`, keeps the temp file in the **same directory** as the
ledger (so the rename is a same-filesystem atomic operation on POSIX and on
Windows), and removes the temp file only when the replace did not happen. A
reader therefore sees either the whole old ledger or the whole new one.

### 2. Fail-closed now covers writes, not just reads

New `LedgerWriteError(LedgerError)`: if the ledger cannot be written
(read-only directory, full disk, lost permission), `consume` raises with a
Persian sentence instead of letting an `OSError` escape the agent. The
optimistic entry is rolled back, so a refused turn is not counted. `Dream`
already turns any `LedgerError` into the turn's reply, so an unmeterable turn
is refused — an unmeterable turn is not a free turn.

`_load` also separates "file does not exist" (a fresh ledger: fine) from
"file cannot be read" (permissions, a directory in the ledger's place,
non-UTF-8 bytes: corruption, refuse).

### 3. Two agents over one ledger no longer lose entries

`consume` and `usage` re-read the file before counting, so a second CLI run,
a second process, or a long-lived agent object cannot append onto a stale
snapshot and silently erase turns another writer recorded. The guest quota is
therefore shared across processes: 20 turns from one object and the 21st from
another is still refused. (A full cross-process lock is deliberately not
here: read-then-atomic-replace is the cheap 95% and adds no dependency.)

### 4. Router priority is now really hosted → Ollama → BYOK → echo

Before, an API key pointing at a **custom** base URL returned `byok` even
when a local Ollama was configured — BYOK jumped the queue. Now:

1. `hosted` — key **and** official base URL (unset base = official default).
2. `ollama` — `OLLAMA_HOST` set. Without an official key, the local server
   wins: it is the more private option.
3. `byok` — a custom (non-official) base URL, with or without a key.
4. `echo` — nothing configured. An official base URL with *no* key is not a
   route, so it falls through to echo instead of pretending to be BYOK.

An explicit `DREAM_BACKEND` still wins over the whole table. Official-base
matching now ignores a trailing slash and case (`HTTPS://API.OPENAI.COM/v1/`
is still hosted), while look-alikes (`https://api.openai.com.evil.example/v1`,
plain `http://`) are correctly BYOK, not hosted.

### 5. Plan-name normalisation lives in one place

`_plan_name()` is now the single normaliser used by `_resolve_plan`,
`ledger_attached`, and `Ledger.__init__`. Unset / empty / whitespace-only
`DREAM_PLAN` means `local` everywhere (previously `DREAM_PLAN="   "` was a
configuration error in one path and "attached" in another); a non-blank
unknown name is still an error, never a silent downgrade to free unlimited.
A whitespace-only `DREAM_LEDGER` no longer attaches a ledger or becomes a
literal `"  "` file name.

### 6. `Dream.ledger_attached`

A read-only property so callers can ask the acceptance question directly:
`Dream(store, EchoBackend())` on the default local plan has
`ledger_attached is False` and `ledger is None`. It is `True` for a metered
plan, `True` when only `DREAM_LEDGER` is set, and — deliberately — `True`
when the plan name is misconfigured, because the fail-closed gate is still
on.

with `{"ts"}`-only entries — no message text, no keys, no paths; `/usage`
(phone-reachable) names the plan and the counts, never the ledger path; the
corruption and quota sentences name `DREAM_LEDGER`/`DREAM_PLAN` as
*variables* but never print their values.

## Deliberately not done

- No cross-process file lock (`fcntl`/`msvcrt`): platform-specific, and the
  re-read + atomic replace covers the realistic single-user case.
- No ledger rotation, export, or pruning: the file grows one small entry per
  metered turn. Worth a future session if a heavy plan is ever sold.
- No prices: paid plans still carry `price: null` +
  "TBD after cost measurement". The tests pin the rule, not numbers.
- No settings UI, no desktop wiring — that is S05.
