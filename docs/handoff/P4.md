# P4 handoff — Workspace, Projects 2.0, and agent modes

## Delivered

P4 adds a first-class local-first workspace and agent modes without modifying P0–P3 owned central files.

- `dream/workspace/`: path-safe roots (pointers, never copies), bounded/lazy listings, sanitized preview (CSV charts, no exec), Projects 2.0 overlay (in-place adopt, session move, settings).
- `dream/agentmodes/`: `/plan` (plan-then-execute), `/goal` (objective + acceptance criteria with honest reports), `/stop` (engine cancellation token + live status), live subagent registry, `@file` `#conversation` `/commands` `!shell`.
- `dream/bridge/methods_workspace.py`: auto-discovered `workspace.*` handlers.
- `tools/workspace_probe.py`: independent offline probe; `cli.py` untouched.
- `/workspace` and `/agents`: auto-registered desktop routes, typed wrappers that call `echo-workspace` when `client.transportKind === 'echo'`, file browser + preview, agent-mode indicator, subagent panel, eight locale namespaces.
- `apps/desktop/src/routes/projects.tsx` upgraded in place (named export kept). Existing `project.*` RPCs and tests remain the S06 surface.
- API/user docs and offline security tests.

## Architecture decisions

1. **Pointers, not copies.** Importing a folder records the resolved real path. Listings and previews read that path. A later write on disk is visible without a second ingest.
2. **Domain seam.** `methods_workspace.py` can only publish `workspace.*` names. Projects 2.0 extras (`project_adopt`, settings, move session) live under that prefix so they cannot collide with built-in `project.*`.
3. **Echo isolation.** The central bridge client is untouched. Wrappers branch on `transportKind === 'echo'` and call `echo-workspace.ts`.
4. **Honest goals.** Criteria that require network or similarly disabled capabilities produce `status=unable` and `could not meet …`. Completeness is never implied.
5. **True cancel.** Plan/goal loops check a threading event. `/stop` sets it; status reports `live: true`. A UI-only spinner is not used as a source of truth.
6. **Hooks.** `AgentModePromptProvider` implements `contribute_prompt` / `expose_tools` for `ProviderManager`. Dream already fans `contribute_prompt`; the provider is tested when registered.

## Security posture

Path resolution refuses `..`, absolute paths, null bytes, symlink roots, and symlink escapes. Preview never executes; HTML is stripped of script/style/handlers; password/token/bearer values are redacted. `!shell` is classified (safe / guarded / dangerous), runs with a reduced environment, `shell=False`, network off, and requires approval except for the safe tier.
