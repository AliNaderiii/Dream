## S15c CI follow-up

The local environment does not provide `cargo`, so Rust Clippy could not be rerun
locally. The first relevant CI diagnostic from the previous single-instance
callback was:

> warning: using `map` over an `Option` value, where `inspect` would be more appropriate

The callback now uses `if let Some(window)` and explicitly logs failures from
`show` and `set_focus`, avoiding `map` for side effects and discarded `Result`
values. It uses the shell's existing non-Android/non-iOS desktop gate. The unsupported
`unminimize` call was removed.

`AppState` now has a matching unit test for the intended default: the main-window
close action quits the application (`close_to_tray == false`).
