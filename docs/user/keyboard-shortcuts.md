# Keyboard Shortcuts

`⌘` on macOS, `Ctrl` on Windows/Linux.

| Shortcut | Action |
| --- | --- |
| `⌘ N` | New session |
| `⌘ B` | Toggle sidebar |
| `⌘ K` | Open command palette |
| `⌘ ,` | Open settings |
| `⌘ 1` | Dashboard |
| `⌘ 2` | Projects |
| `⌘ 3` | Memory |
| `⌘ 4` | Skills |
| `⌘ 5` | Connectivity |
| `⌘ ⇧ L` | Toggle light/dark theme |
| `←` / `→` (on the resize handle) | Shrink / grow the sidebar |

## Command palette

Press `⌘ K` and type to search every command, then `Enter` to run it. The
palette is the keyboard-only way to reach any action — including actions that
have no dedicated shortcut.

## Language switching

From the **status bar** (bottom edge) click the language indicator and choose a
language, or go to **Settings → Language**. Persian is the only right-to-left
language.
