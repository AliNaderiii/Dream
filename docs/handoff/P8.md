## Handoff for existing surfaces

How research / dataqa / workspace / providerhubs should consume P8 primitives (light imports only; zero-behavior swaps):

- **Button** — drop-in replacement for any action control; variants `primary`/`secondary`/`ghost`/`destructive`/`danger-outline`; sizes `sm`/`md`/`lg`/`icon`/`icon-sm`; `loading` state preserves width.
- **Card** — wrap existing panels; `CardHeader`/`CardTitle`/`CardDescription`/`CardContent`/`CardFooter` (not edited here, keep existing API).
- **Dialog** — use `Dialog`/`DialogTrigger`/`DialogContent`/`DialogHeader`/`DialogTitle`/`DialogDescription`/`DialogFooter`; focus trapped automatically; `hideClose` available.
- **Input** — replace form fields; pass `label`, `hint`, `error`, `leading`; `aria-describedby` and `aria-invalid` handled.
- **Tabs** — use `Tabs` with `items`, `label`, `variant`; keyboard arrows + RTL handled.
- **Badge** — status pills; never color-only (pair with text).
- **Table** — new; wrap tabular data with `Table`/`TableHeader`/`TableBody`/`TableRow`/`TableHead`/`TableCell`.
- **Progress** — new; `value`, `max`, `label`; `role="progressbar"`.
- **EmptyState** — new; `title`, `description`, `action`; `aria-label` on region.
- **Skeleton** — use while loading; `SkeletonCard` for list patterns.
- **Toast** — viewport with `notice` array; `role="status"`/`"alert"`; `dismissLabel` required.
- **Tooltip** — wrap triggers; `TooltipProvider` with 600 ms delay.

No page-tree rewrites required. If a surface already uses a primitive, refine imports to include `cn` and token utilities; do not swap APIs.
