# Dream — User Documentation

Dream is a local-first personal assistant that keeps its memory on your
machine, asks before it does anything irreversible, and speaks Persian as well
as English (plus six more languages).

## Getting help

- Repository: <https://github.com/AliNaderiii/Dream>
- Issues: <https://github.com/AliNaderiii/Dream/issues>
- Report a bug with `dream --debug` output attached (it never contains your API
  keys — those live in the OS keychain, not in logs).
