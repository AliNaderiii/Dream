## What shipped

A commercial kernel and an honest product story, on top of the existing
local-first agent:

1. **`dream/commerce.py`** — seven plans (`local`, `guest`, `daily`,
   `individual_monthly`, `individual_yearly`, `team`, `company`), currency
   IRR, `price: 0` for the two free plans and `price: null` +
   "TBD after cost measurement" for every paid plan (no invented numbers).
   JSON usage ledger with atomic writes; a ledger is attached only when
   `DREAM_PLAN` is not `local` or `DREAM_LEDGER` is set; metered plans fail
   closed on unreadable/invalid/malformed ledgers and on unknown plan names;
   guest blocks the 21st turn with a Persian quota sentence; local runs with
   no ledger file.
2. **`dream/router.py`** — fixed priority hosted → Ollama → BYOK → echo,
   resolved deterministically from configuration (no network probes), each
   route carrying an English + Persian sentence stating whether data leaves
   the machine.
3. **`dream/agent.py` (ledger hook only)** — `Dream.run` consumes a turn
   when a ledger is attached; quota/corruption/configuration refusals return
   a normal `Turn` whose reply is the Persian sentence (no backend call, no
   memory write, nothing appended to the ledger). Construction never raises
   on a misconfigured ledger.
4. **`cli.py`** — `dream --plan`, `dream --usage`, `dream --route` flags and
   `/plan`, `/usage`, `/route` slash commands; `KNOWN_COMMANDS`,
   `_HELP_FRAGMENTS`, and `_PHONE_POLICY` updated together (all three
   read-only and phone-allowed; the locked refused set `/dedupe`, `/pin`,
   `/exit` is unchanged).
5. **`.env.example`** — documents `DREAM_PLAN` and `DREAM_LEDGER`; both are
   read via `os.environ.get` in product code (M23 scan green).
6. **`pyproject.toml`** — `web` (fastapi, uvicorn) and `data` (nbformat)
   extras.
7. **`examples/iranian-sales-sample.csv`** — hand-made Iranian sales extract
   with Persian headers + `examples/README.md`.
8. **`README.md`**, **`CHANGELOG.md` (Unreleased)**, **`docs/PRODUCT.md`** —
   Dream 0.2 described as a local-first Persian agent + Tauri desktop, plans
   table, metering/privacy behaviour; no marketing claims.
9. **`tests/test_commerce.py`** (28 tests) and **`tests/test_router.py`**
   (12 tests) pinning the acceptance criteria; both files obey the M16
   conditional-assertion and Persian-escaping conventions.

## Design decisions worth knowing

- **Fail-closed is a reply, not a crash.** Every ledger refusal (quota,
  corruption, unknown plan) becomes the turn's Persian reply, so every caller
  (CLI, bridge, phone) gets a `Turn` and no path grants free usage on a
  broken meter. `Dream.__init__` never raises on a bad ledger.
- **Quota windows are local-calendar based** (day/month/year per plan) and
  counted from entry timestamps, so a new day resets the guest quota
  naturally. Limits are single-point constants for post-measurement tuning.
- **The router never probes the network** — it resolves from configuration,
  which keeps it deterministic, offline, and testable; the privacy sentence
  is derived from the same resolution, so it cannot contradict the route.
- **Phone parity is inherited**: `dream/telegram.py` imports
  `PHONE_COMMANDS`/`PHONE_HELP` from `cli.py`, so the three new read-only
  commands became phone-reachable with zero edits to `telegram.py`.
