1. **Research Route & Navigation** (`/research`)
   - Auto-registered via P0 route-registry seam

2. **New Research Flow**

   - Human-in-the-loop checkpoint
   - Displays research questions, hypotheses, methodology, outline tree
   - Approve / Modify / Cancel actions
   - Inline plan editor on Modify

4. **Live Structured Execution Trace**
   - Collapsible, labeled step cards (Analyze | Plan | Discover | Code | Execute | Observe | Evidence | Section)
   - Per-step status (pending/running/done/failed/blocked)
   - Live output (stdout/stderr, truncated + expandable)
   - Elapsed time, token/cost badges
   - Timeline of sections
   - Overall progress bar + ETA
   - Prominent Stop button (calls `research.stop`, reflects real server state)
   - "Fix & retry" affordance for blocked/error steps

5. **Execution Trace Inspector**
   - Side panel showing every tool call
   - Args (collapsed), result excerpt, error, risk tier
   - Filter by phase/tool/status

6. **Report Viewer**
   - Markdown rendering with syntax-highlighted code blocks, tables, inline figures
   - Export bar (Markdown, PDF, reproduction ZIP, .provenance.json)
   - Figure gallery
   - Claims ⇅ evidence integrity view (statistics-integrity skill)

7. **Domain Wrapper & Echo Mock**
   - `apps/desktop/src/lib/bridge/research.ts` — typed `research.*` calls, stream subscription, error mapping
   - `apps/desktop/src/lib/bridge/echo-research.ts` — deterministic mock runtime with realistic multi-section plan, trace with self-corrected errors, report, and figures
   - Browser dev works without sidecar (mirrors `echo-data.ts` pattern)

8. **State Management**
   - Zustand store (`research-store.ts`)
   - Per-session status, streaming buffer (bounded to 500 events)
   - Derived selectors for filtered steps

9. **Localization**
   - New `research` namespace across all 8 locales (en, fa, zh-CN, ja, es, de, fr, ko)
   - 100% identical key trees
   - Full FA RTL support
   - Proper plural/date handling

## Architecture Decisions

1. **P0 Seam Integration**: Route auto-registered via `import.meta.glob` — no edits to `App.tsx` or `activity-rail.tsx`
2. **Zustand Over Context**: Per-session streaming state isolated to prevent cross-session leaks
3. **Bounded Buffers**: 500 events max per session (pagination-ready for long traces)
4. **Defensive Redaction**: Frontend redacts secrets even if backend misses them
5. **Echo Mock Parity**: Deterministic PRNG ensures same trace every run (testable, predictable)
6. **Sanitized Markdown**: Custom renderer strips scripts/exfiltration (production would use remark/rehype)
