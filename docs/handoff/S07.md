# S07 — Conversation UX

## Summary

S07 makes the chat surface trustworthy by adding streaming-aware tool cards, a
human approval dialog, and stop-button cancellation — all inside the existing
pane workspace. The approval gate stays fail-closed: without an explicit
approver, dangerous tools are blocked.

## What was delivered

### 1. Tool cards in the transcript

Each tool call in a turn is rendered as a compact card above the assistant's
text bubble. Cards show:

- **Tool name** (e.g. `calculate`, `write_file`)
- **Arguments summary** (truncated JSON)
- **Status**: `ok` · `error` · `blocked` · `pending`
- **Result excerpt** (when status is `ok`)

Cards are typed as `ToolCardEntry` in `types/index.ts` and attached to
`Message.toolCards`.

**Component**: `components/chat/tool-card.tsx`

### 2. Approval dialog for dangerous tools

When the bridge returns `APPROVAL_REQUIRED` (code `-32005`), the pane shows a
modal dialog with three actions:

| Action | Effect |
|--------|--------|
| **Allow once** | Resolves the approval, executes the tool, asks again next time |
| **Always allow this tool this session** | Adds the tool to a per-pane `alwaysAllowTools` set; future calls for that tool skip the dialog |
| **Deny** | Resolves the approval as denied; renders a `blocked` tool card; turns stays fail-closed |

Dialog copy is bilingual (English + Persian) and generated via
`scripts/generate-locales.mjs`. The dialog traps focus and dismisses on
Escape (which denies).

**Component**: `components/chat/approval-dialog.tsx`

### 3. Stop button

The stop button (already present) calls `conversation.stop` to cancel
in-flight work. The pane clears its sending state cleanly.

### 4. Pane chat store extensions

`stores/use-pane-chat-store.ts` gained:

- `setPendingApproval(paneId, approval | null)` — shows/hides the dialog
- `alwaysAllowTool(paneId, toolName)` — session-scoped allowlist
- `isAlwaysAllowed(paneId, toolName)` — lookup for the retry loop
- `addToolCard` / `updateToolCard` — card lifecycle helpers

### 5. Echo transport updates

The echo bridge transport (`lib/bridge/client.ts`) returns tool cards in its
`conversation.send` result so the UI is exercisable without a sidecar.

### 6. Locale keys

Added `chat.approval.*` keys in all 8 languages via the locale generator:

- `title`, `description`, `allowOnce`, `alwaysAllow`, `deny`,
  `waitingForApproval`, `blocked`, `blockedByUser`

### 7. RTL safety

- The textarea uses `dir="auto"` so Persian input is right-aligned.
- All card/dialog layout uses logical properties (`start`/`end`), never
  hard-coded `left`/`right`.
- The composer form does not break under RTL.
