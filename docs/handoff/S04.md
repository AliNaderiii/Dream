## What shipped

One clear no-VPN first-five-minutes story on Windows:

1. **`run.bat` is the primary launcher.** Double-click it. It `cd`s to the
   repo, creates `.venv` if missing (or prints the one command
   `python -m venv .venv` and pauses), installs `pip install -e .` when
   `import dream` fails, refuses to start without Ollama, and otherwise
   starts `cli.py --backend ollama` with `DREAM_MODEL=qwen2.5:7b`.
2. **Ollama missing → English always, Persian if the console is UTF-8.**
   `run.bat` calls `python doctor.py --message ollama-missing`, which prints
   both languages and the official URL `https://ollama.com/download`, then
   the script pauses so the window stays readable.
3. **`doctor.py` failures are readable.** Every `FAIL` line stays English.
   When stdout/stderr can encode Persian, the same line also carries a
   Persian gloss, and the summary on stderr is bilingual. Offline checks
   are unchanged for existing tests.
4. **Docs match the scripts.** `docs/user/quick-start.md` documents the
   double-click path, `pip install -e ".[web]"` and `".[data]"`, and labels
   the other `.bat` files. README onboarding points at **one** Windows
   launcher.
5. **Working scripts were not deleted.** `check.bat` is offline
   diagnostics. `Dream.bat` and `Dream-Start.bat` stay the experimental
   desktop-window launchers and now say so in a `REM` line.

`run.bat` and `check.bat` stay ASCII + CRLF. Persian lives in `doctor.py`
as `\u` escapes so the `.bat` files never have to carry UTF-8.
