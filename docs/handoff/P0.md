# P0 integration seam log

## P0-FIX decisions

- **F1 — silent normal absence:** `find_spec()` returning `None` for a domain's
  missing `tools.py` now skips silently. Only a real module with no usable file
  origin, a package escape, or an import/dependency failure is quarantined.
  Stock-tree discovery has an empty `dream.extensions.errors` list.
- **F2 — immutable publication:** bridge discovery permits registration only
  while it is discovering. `Registry.publish()` removes and error-logs every
  key colliding with the built-in table, then freezes the extension mapping.
  Built-ins always win; there is deliberately no `OVERRIDE` bypass.
- **F3 — production route graph:** extension pages use a non-eager glob with
  test exclusion. Existing route filenames are frozen in a denylist, so they
  never enter the extension registry or the entry graph. New domain pages are
  default-exported `src/routes/<domain>.tsx`; optional `.route.ts` metadata is
  the only eager metadata import.
- **F4 — reachability:** ActivityRail appends de-duplicated `registeredNav`
  items after its unchanged primary items, preserving the existing icon,
  tooltip, active marker, and RTL behaviour. AppShell now uses an extension
  route's i18n label for its title fallback.
- **Security review:** discovery remains sorted, package-local, path-checked,
  and contains no `exec` or `eval`. Import failures cannot remove existing
  handlers or crash bridge startup.
