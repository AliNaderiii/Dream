# S11 — Iranian first-run + chat Council button

**Status: Gate G11 met.** The dashboard first-run card now offers Aval AI
as the recommended hosted path with a plain leave-the-machine line. The
chat composer has a compact opt-in Council review button that calls
`council.run` with the current composer text (or the last user message),
navigates to `/subagents` after a successful run so the existing
three-column council widget renders the result, and shows a ledger
`refusal` inline instead of inventing a winner. Send / `conversation.send`
never starts a council, the kernel was not touched, and no IRR price or
new model id was invented.

## What changed

### Desktop — `apps/desktop/src/components/billing/first-run-card.tsx`

- The card now renders three options on a responsive grid:
  `sm:grid-cols-2 lg:grid-cols-3`. Echo and Ollama are unchanged; BYOK is
  preserved as an optional extra.
- The new middle card is Aval AI, framed as the **recommended hosted
  path**: a `Sparkles` badge labelled "Recommended" sits at the top-right,
  the title and description come from `firstRun.avalTitle` /
  `firstRun.avalDesc` / `firstRun.avalCta` / `firstRun.avalBadge`, and the
  description carries the honest line *"`api.avalai.ir`. Your prompts
  leave this machine."* — never a "stays local" claim for the hosted
  option.
- The Aval CTA calls `navigate('/providers')`. Aval is the first row of
  the provider catalog (S09), so the user lands directly on its add
  screen; no new page, no new route, no kernel change.

### Desktop — `apps/desktop/src/components/chat/council-button.tsx` (new)

- A small `CouncilButton` (`Scale` icon, secondary variant) sits next to
  Send in `PaneChat`. It receives the current `input` text and the pane's
  message list; the prompt is the composer text when non-empty, otherwise
  the most recent user message, otherwise the locale-backed empty hint
  (`chat.councilEmpty`).
- Clicking it calls `council.run` with `{prompt}` (echo members by
  default — exactly the S10 contract) and either navigates to
  `/subagents` (success) or shows the ledger's `refusal` as a small
  inline banner (no fake winner, no fabricated council output). The
  `error` path renders a localised message and does not navigate.
- The component is ~80 lines; `pane.tsx` gained 6 lines total: the
  import and one `<CouncilButton ... />` element in the composer. Send
  and Stop are untouched. `conversation.send` is never called from this
  file.

### Desktop — `apps/desktop/src/components/panes/pane.tsx`

- Two new lines near the Send/Stop button: an import and one
  `<CouncilButton input={input} messages={transcript?.messages ?? []}
  disabled={transcript?.sending} />`. The control is disabled while the
  pane is already streaming so it cannot race a normal send.

### i18n — `apps/desktop/scripts/generate-locales.mjs`

- New keys in `common.firstRun`: `avalTitle`, `avalDesc`, `avalCta`,
  `avalBadge`.
- New keys in `chat`: `councilButton`, `councilButtonTitle`,
  `councilStarting`, `councilEmpty`, `councilRefusal`, `councilError`.
- All 8 languages carry the same 14 namespaces × 386 keys tree. The
  generator's coverage check (`flatten(en)` vs `flatten(lang)`) is the
  only contract; the JSON files were regenerated from it.

## What did not change

- `dream/commerce.py`, `dream/council.py`, `dream/agent.py`, the
  bridge, the Rust side, `apps/desktop/src/lib/bridge/**` — the kernel
  is untouched. No new model ids, no invented IRR, no payment flow, no
  messenger integration, no `DREAM_HOSTED_BASE_URL`, no change to
  `subagents.tsx` / `projects.tsx` / `scheduler.tsx` / `pane-workspace.tsx`
  / `first-run-card.test.tsx` or any other test.
- The `CouncilDialog` from S10 is not touched. The chat composer
  shortcut is a one-button form of the same flow: `council.run` →
  `council.get` (polled by the existing widget) → winner once the judge
  completes.

## Why this honours the brief

- "Iranian first-run" — the new Aval card is the recommended hosted
  path, honest about leaving the machine, and links straight to the
  provider card that already exists.
- "Chat Council button" — opt-in only, tiny, never auto-starts on Send,
  shows the refusal plainly, reuses the S10 widget for display.
- "Do not rebuild first-run or chat composer" — neither page was
  rebuilt; the first-run card is a wrapped 3-up grid, the composer is
  one extra button.
- "8 identical key trees" — `generate-locales.mjs` is the single source
  of truth, the coverage check passes, the JSON files are
  machine-generated.
