# P12 — Google Workspace read-only OAuth

**Base:** `origin/main` at `v0.4.3` (`77b2190`). New domain only.

## What shipped

- `dream/gws/**` + `methods_gws.py` → `gws.status`, `gws.oauth_begin`,
  `gws.oauth_complete`, `gws.disconnect`, list RPCs
- Chat tools `gmail_list`, `calendar_list`, `drive_list` (guarded);
  `gmail_send` dangerous and refused
- UI `/google` (`gws.tsx` + `gws.route.ts`)
- HTTPS allow-list: `oauth2.googleapis.com`, `gmail.googleapis.com`,
  `www.googleapis.com`
- Loopback redirect only; tokens in `KeychainCredentialStore` account `gws`

## What this is not

- Not unrestricted internet / SSRF off
- Not Gmail send, Drive write, or Calendar insert
- Not Instagram / Facebook login
- Does not rewrite `client.ts` or `methods.py`
